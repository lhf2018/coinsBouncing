# 弹弹金库

弹弹金库是一个面向手机竖屏的网页游戏，也可以用桌面鼠标游玩。传送带自动送出带金额的数字，数字在盘面上弹跳，碰到已上阵的弹块会增值，落到底部后计入钱包和本关进度。

## 本地运行

需要 Node.js 20.19+（20.x）或 22.12+，以及 npm。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173/`。

## 玩法

1. 开局有 40 金币，盘面和库存各有一个 `+2` 弹块。点击「购买数字」可以获得 `+1`、`+2`、`×1.1` 或 `×1.2`。首次购买花费 20 金币，之后每次成功购买都会涨价。
2. 将库存里的弹块拖到已解锁的盘面槽位。也可以先点选弹块，再点目标格。两个相同的弹块放在同一格会合成更高一级的弹块，例如两个 `+2` 合成 `+4`。
3. 点击带标价的槽位可以解锁更多摆放位置。加法弹块增加固定金额，倍率弹块按比例增加金额，结果向上取整。
4. 底部「升级」和速度卡都可以打开传送带工坊。每次速度升级固定花费 100 金币。每装一个齿轮固定花费 180 金币，使之后新发出的数字初始金额增加 1 金币，最多安装 3 个。
5. 三关的累计入账目标分别为 300、1,800、7,000 金币。消费只扣钱包余额。达到本关目标后，点击「下一关」继续。

盘面上的数字会相互碰撞。数字撞到弹块时会旋转和放大，开启系统的「减少动态效果」后会关闭这两种视觉效果。

## 构建和预览

```sh
npm run build
npm run preview
```

构建会先运行 TypeScript 类型检查，再生成 `dist/`。预览地址以终端输出为准。

## 项目结构

| 路径 | 职责 |
| --- | --- |
| [src/game.ts](src/game.ts) | Rapier 2D 物理世界、金币结算、购买合成、升级和存档 |
| [src/main.ts](src/main.ts) | 盘面和工坊界面、点击与拖拽、游戏循环 |
| [src/render.ts](src/render.ts) | 传送带与数字绘制，通过 PixiJS WebGL 显示，支持 Canvas 2D 回退 |
| [src/token.ts](src/token.ts) | 测量数字轮廓，计算碰撞空间 |
| [src/style.css](src/style.css) | 盘面、工坊与操作区样式 |

进度自动保存在当前浏览器的 `localStorage`。刷新会恢复已保存的钱包、关卡、弹块和工坊升级。传送带和盘面上的在途数字会重新生成。
